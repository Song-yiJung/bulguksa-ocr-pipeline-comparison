# 지시문 변경 내역

세 파일은 모델에 보낸 원문 그대로이다. 줄 단위 차이는 `diff_v1_v2.diff`, `diff_v2_v3.diff`에 있다.

## v1 → v2 (초기 → 수정)

초기 지시문은 다섯 항목(판독 순서, 오독 보정, 노이즈 제거, 누락 요소 및 구자체 복원, 출력 형식)으로 이루어졌다. 수정 지시문은 이를 열 항목으로 다시 구성하였다.

삭제
- 2항 "도메인 기반 오독 보정" (예: 金利石塔 → 舍利石塔)
- 4항 가운데 "누락된 가타카나 및 히라가나 조사를 문맥에 맞게 복원"

추가·재구성
1. 표·목록 레이아웃 보존: 반복 기호 〃·全 보존, 행정 계층 축약 규칙
2. 일본어 법령체 접속사·조사 판독: 又ハ/及, 공문서 상투어
3. 표준 조사서 템플릿: 一~八 고정 필드
4. 숫자·도량형: 자릿수 구분 보존, 연호 표기, 불명확한 숫자는 □
5. 구자체 보존: 臺/台 등 8쌍 예시, 유사 자형 주의
6. 고유명사 목록: 인명, 지명, 불교·미술사 용어, 사찰명
7. 환각 방지: 불확실한 글자 뒤 [?], 판독 불가 □ 또는 (판독불가)
8. 인장·직인 처리: 붉은 인장 위치에 (鈐印) 또는 (직인: 내용)
9. 문서 레이아웃: 세로쓰기, 공문서 양식 칸 목록(發送/記帳/鈐印/校合/淨寫 등) 유지
10. 출력 형식: 순수 텍스트, 연구자 한글 주석을 원문 한자로 환원, 단락 구분 유지

## v2 → v3 (수정 → 상세화)

어휘 보강이 중심이며, 표기 규칙 세 가지가 함께 추가되었다.

어휘 보강 (기준 판독문 15건에서 3개 이상 문건에 나타나는 문자열과, 판독문 구조화 과정에서 확인한 결재 직책·기관명)
- 3항: 조사서 필드값 (所在地, 地番, 地目, 地積의 예, 所有者 항목)
- 6항: 지명(慶尚北道, 內東面 進峴里), 金銅阿彌陀如來坐像, 불국사 전각명(紫霞門·泛影樓·大雄殿·極樂殿·無說殿), 사찰명(奉恩寺·祇林寺)
- 11항(신규): 기안 용지 양식 필드, 결재선 직책명, 관련 기관명

표기 규칙 (11항)
- 인장이 찍힌 자리는 (鈐印)으로 일관 표기
- 미날인 표시 '/' 보존
- 件名 항목은 별도 행으로 분리

기타
- 서두의 문자 구성에 "한국어" 추가, 띄어쓰기 한 곳 수정
