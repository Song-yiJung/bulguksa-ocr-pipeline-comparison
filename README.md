# Bulguksa Administrative Corpus
## 식민지기 불국사 행정문서 코퍼스

> 본 리포지토리는 작성 중인 학술논문의 부속 자료입니다. 
> 논문 게재 확정 후 정식 공개될 예정이며, 현재는 준비 단계입니다.

## 개요

본 리포지토리는 1930년대 식민지기 불국사 보물 지정 과정과 관련된 
조선총독부박물관 소장 문서를 텍스트 데이터화한 코퍼스입니다.
세 가지 문서 유형 — 기안문서, 보물 목록, 편지·서신 — 에 집중하여 
구성하였으며, 특히 1929년 나가오 킨야(長尾欽彌)의 조선총독부박물관 
기부 문건을 핵심 자료로 합니다.

## 자료 범위

- **사료 출처:** 국립중앙박물관 소장 조선총독부박물관 문서
- **시기:** 1929-1934년 전후 (불국사 보물 지정 관련)
- **문서 유형:**
  - 기안문서 (Drafts of Official Documents)
  - 보물 목록 (Treasure Inventories)
  - 편지·서신 (Correspondence)
- **핵심 컬렉션:** 1929년 나가오 킨야 기부 문건

## 본 자료와 박사학위논문의 관계

본 자료는 저자의 박사학위논문 연구의 일부입니다. 학위논문은 
불국사를 대상으로 한 식민지기 문서를 보다 포괄적으로(보존, 고적조사, 
보물 지정, 기부, 행정 등) 다루며, 관련 종합 자료는 별도 리포지토리에 
정리됩니다.

## 폴더 구성

bulguksa-administrative-corpus/
- 01_source_metadata/     사료 출처 메타데이터
- 02_drafts_official/     기안문서 텍스트
- 03_treasure_lists/      보물 목록 텍스트
- 04_correspondence/      편지·서신 텍스트
- 05_structured_data/     정리된 표·통계 데이터
- 06_analysis_code/       분석 코드 및 프롬프트
- 07_figures_tables/      논문 그림·표 원본 데이터

각 텍스트 폴더에는 다음 두 종류의 파일이 들어갑니다.
- `extracted_text/`: 1차 OCR로 추출한 텍스트
- `corrected_text/`: Gemini API로 의미론적 교정을 거친 2차 텍스트

## 데이터 생성 방법

본 자료는 두 단계 파이프라인으로 생성되었습니다.

1. **1차 추출:** PaddleOCR (오픈소스 OCR 라이브러리)
2. **2차 교정:** Google Gemini API (gemini-2.5-flash, 2026년 ○월)
